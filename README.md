# thai-reading — แปลงข้อความไทยเป็น "คำอ่าน" ให้ AI พากย์เสียงออกเสียงถูก

โมเดลเสียง AI หลายตัว (เช่น MiniMax H3) อ่านภาษาไทย **ตามตัวสะกด** จึงพลาดกับคำที่เขียนไม่ตรงเสียง
เช่น ตัวการันต์ (พระปรางค์) ร ไม่ออกเสียง (สร้าง) สระซ่อน (เสด็จ) พยางค์เชื่อมที่มองไม่เห็น (ราชการ = ราด-ชะ-กาน)
คำบาลี-สันสกฤต อักษรย่อ (พ.ศ. กม. รศ.) และตัวเลข
โปรแกรมนี้เปลี่ยนข้อความเป็น **คำอ่าน** แล้วคุณป้อนคำอ่านให้โมเดลเสียง ส่วนซับไตเติลยังใช้ข้อความเดิมที่สะกดถูก

| ข้อความเดิม | ส่งให้โมเดลเสียง |
|---|---|
| พระปรางค์สูงตระหง่าน | พระ-ปราง-สูง-ตระ-หง่าน |
| พระอุโบสถ | พระ-อุ-โบ-สด |
| ค่าธรรมเนียม 200 บาท | ค่า-ทำ-เนียม สองร้อย บาท |
| พระพุทธศาสนา | พระ-พุด-ทะ-สาด-สะ-หนา |
| สร้างเมื่อ พ.ศ. 2560 | สร้างเมื่อ พุทธศักราช สองพันห้าร้อยหกสิบ |
| เปิด 08:30 น. | เปิด แปด นาฬิกา สามสิบ นาที |
| เปิด 10:00-16:00 | เปิด สิบ นาฬิกา ถึง สิบหก นาฬิกา |
| ลด 50% | ลด ห้าสิบ เปอ-เซ็น |
| รศ.ดร.สมชาย | รอง-สาด-ตรา-จาน ด๊อก-เต้อ สมชาย |
| ผู้ใหญ่ ร้านอาหาร | ผู้ใหญ่ ร้านอาหาร *(คำทั่วไป ไม่แตะ)* |

ไม่อยากได้ขีด `-` ใส่ `--style dict` → ได้**คำอ่านแบบพจนานุกรม** เขียนติดกัน เช่น `ค่าทำเนียม สองร้อย บาท`,
`พระอุโบสด`, `พระพุดทะสาดสะหนา` (ข้อ 6)

- **ที่อยู่ในเครื่อง:** `D:\AntigravityRepo\tools\thai-reading` (ย้ายมาจาก `D:\AntigravityRepo\thai-reading` เมื่อ 2026-10-23)
- **GitHub (สาธารณะ):** https://github.com/chatcpeg/thai-reading
- **เวอร์ชัน:** 1.5.0 (เพิ่ม `--h3` ชุดตั้งค่าสำหรับ MiniMax H3, `data/voice_fixes.txt` คำที่เจ้าของฟังเลือกแล้ว, `--repeat` เขียน ๆ เป็นคำซ้ำ — วิธีใช้ใน [การใช้งาน.md](การใช้งาน.md) ข้อ 6)
- **ต้องมี:** Python 3.8+ อย่างเดียว ไม่ต้องติดตั้งไลบรารีเพิ่ม (การสร้างข้อมูลใหม่เท่านั้นที่ต้องใช้ pythainlp)
- คู่มือทีละขั้นสำหรับคนทั่วไป: [การใช้งาน.md](การใช้งาน.md) · สำหรับ AI agent: [AGENTS.md](AGENTS.md)

## 1. ฟีเจอร์

**คำอ่าน**
- พจนานุกรมคำอ่าน ~33,000 คำ จาก Wiktionary (ฉบับอังกฤษ + ไทย) รวมคำยืมบาลี-สันสกฤต ผ่านการตรวจความสมเหตุสมผลแล้ว
- **แบบ C** — พยางค์ต่อกันด้วยขีด `-` (ตระ-หง่าน) ทดสอบกับ MiniMax H3 แล้ว แบบขีดออกวรรณยุกต์ถูกกว่าและไม่กระตุก
  (แบบเว้นวรรค "ตระ หง่าน" ถูกครึ่งเดียว และเว้นหน้า-หลังคำทำให้เสียงกระตุก ~0.3 วิ)
- **แบบพจนานุกรม** (`--style dict`) — คำอ่านเดียวกัน แต่เขียนติดกันไม่มีขีด (ค่าทำเนียม, ราดชะกาน) ข้อ 6
- **ไม่แน่ใจ = ไม่แตะ:** ผลที่ได้ไม่แย่กว่าข้อความเดิม คำทั่วไป 2,500 คำที่ใช้บ่อยที่สุด และวลีที่ประกอบจากคำทั่วไป ไม่ถูกเปลี่ยน
- ตัดคำด้วย maximal matching จากพจนานุกรม (ไม่ใช่ค้นหาข้อความย่อย จึงไม่ไปแก้กลางคำอื่น)
- คำสมาส: ใส่พยางค์เชื่อมเฉพาะหลัง พุทธ ราช บรม ธรรม ที่ตามด้วยคำนามบาลี-สันสกฤต (พุทธ+ศาสนา = พุด-ทะ-สาด-สะ-หนา)
  คำเรียงแบบไทย (ยามพระอาทิตย์ตก, ประเทศไทย) และคำที่ไม่แน่ใจ คงตามตัวเขียน
- อ่านบาลีอักษรไทย (ธมฺม → ธัม-มะ) ด้วยกฎ 7,700+ รูป (เปิดด้วย `--pali`)

**ตัวเลขและอักษรย่อ** (รายการเต็มในข้อ 7)
- ตัวเลข ทศนิยม หลักพัน เวลา ช่วง วันที่ ระยะเวลา เปอร์เซ็นต์ ติดลบ เงิน เบอร์โทร รหัสไปรษณีย์ อัตราส่วน เลขไทย
- อักษรย่อ: เดือน หน่วย สถานที่ คำนำหน้า ศักราช ไปยาลน้อย/ใหญ่ — เพิ่มเองได้

**ไฟล์**
- .txt .srt .vtt .ass/.ssa .tsv .json .jsonl — แปลงเฉพาะข้อความไทย โครงไฟล์เดิมทุกอย่าง
  (เลขลำดับ/เวลาซับ แท็ก `<i>` `{\an8}` key ของ JSON หัวตาราง TSV ย่อหน้า BOM CRLF NBSP)
- เลือกเฉพาะบาง key / คอลัมน์ได้ (`--keys`)

**ปรับแต่ง**
- สอนคำอ่านเอง (ชนะทุกแหล่ง) · รายการ "คงตามตัวเขียน" สำหรับคำที่โมเดลเสียงอ่านตัวสะกดเดิมได้ดีกว่า
- 3 โหมด: เฉพาะคำหลอกตา / ทุกคำที่อ่านต่างจากตัวสะกด / ทุกคำในพจนานุกรม

**ใช้ได้หลายทาง**
- เมนูโต้ตอบ · ลากไฟล์วางบน .bat · บรรทัดคำสั่ง · stdin · ผลแบบ JSON · Python library
- Windows (`ThaiReading.bat`) · macOS / Linux / Git Bash (`thai-read.sh`)

## 3. ใช้งานด้วยเมนู / ลากไฟล์ (Windows)

### ดับเบิลคลิก `ThaiReading.bat`

```
==== thai_read 1.5.0 - Thai text -> reading (style C) ====
  [1] word / sentence -> reading
  [2] file -> <name>_อ่าน<ext> (.txt .srt .tsv .json .jsonl)
  [3] teach a reading (saved in data/my_readings.txt)
  [S] switch to dictionary style, no - (ค่าทำเนียม)
  [Q] quit
```

| เมนู | ทำอะไร |
|---|---|
| **[1]** | พิมพ์คำหรือประโยค → เห็นคำอ่าน พร้อมรายการคำที่เปลี่ยน แหล่งที่มา และเหตุผล · Enter ว่าง = กลับเมนู |
| **[2]** | ลากไฟล์มาวางในหน้าต่าง (หรือพิมพ์ path) แล้ว Enter → ได้ไฟล์ `_อ่าน` ข้างไฟล์เดิม |
| **[3]** | ใส่คำ แล้วใส่คำอ่าน (เช่น `ธรรมเนียม` → `ทำ-เนียม`) → บันทึกลง `data/my_readings.txt` ใช้ทันที |
| **[S]** | สลับรูปแบบคำอ่าน แบบ C (`ค่า-ทำ-เนียม`) ⇄ แบบพจนานุกรม ไม่มีขีด (`ค่าทำเนียม`) — หัวเมนูบอกแบบที่ใช้อยู่ |
| **[Q]** | ออก |

### ลากไฟล์ไปปล่อยบนไอคอน `ThaiReading.bat`

วางทีละหลายไฟล์ได้ ได้ไฟล์ใหม่ `<ชื่อเดิม>_อ่าน.<นามสกุลเดิม>` วางข้างไฟล์เดิม ไฟล์ต้นฉบับไม่ถูกแก้
หน้าต่างจะรอให้กดปุ่มก่อนปิด (ตั้งตัวแปร `THAI_READ_NOPAUSE=1` ถ้าไม่ต้องการ)

```
บทพากย์.txt  ->  บทพากย์_อ่าน.txt
ซับ.srt      ->  ซับ_อ่าน.srt
```

`ThaiReading.bat` หา Python เองจาก `py -3` แล้วค่อย `python` และคืน code page ของหน้าต่างเดิมให้หลังทำงาน

อยากให้ลากไฟล์ / เมนู ได้แบบพจนานุกรม (ไม่มีขีด) ทุกครั้ง: ตั้งตัวแปร `THAI_READ_STYLE=dict` ครั้งเดียว
(พิมพ์ `setx THAI_READ_STYLE dict` ในหน้าต่าง cmd แล้วเปิดหน้าต่างใหม่ · เลิกใช้: `setx THAI_READ_STYLE c`)

## 4. ใช้งานจากบรรทัดคำสั่ง

```bat
python thai_read.py --text "ข้อความ"                 :: คำอ่าน (หลายบรรทัด = ได้หลายบรรทัด)
python thai_read.py --text "ข้อความ" --json          :: JSON พร้อมรายการคำที่เปลี่ยน
python thai_read.py ไฟล์1.txt ไฟล์2.srt               :: แปลงไฟล์
python thai_read.py ไฟล์.srt --out ผลลัพธ์             :: เก็บผลในโฟลเดอร์อื่น
python thai_read.py --stdin < in.txt                 :: อ่านจาก stdin ทีละบรรทัด
python thai_read.py --teach ธรรมเนียม ทำ-เนียม         :: สอนคำอ่าน
python thai_read.py --menu                           :: เมนู (ค่าเริ่มต้นเมื่อไม่ใส่อาร์กิวเมนต์และรันในหน้าต่าง)
python thai_read.py --version
```

macOS / Linux / Git Bash ใช้ `./thai-read.sh` แทน `python thai_read.py` (อาร์กิวเมนต์เดียวกัน)

### ตัวเลือกทั้งหมด

| ตัวเลือก | ใช้กับ | ทำอะไร |
|---|---|---|
| `--text "..."` | — | แปลงข้อความที่ให้ |
| `--stdin` | — | อ่านทีละบรรทัดจาก stdin (แยกบรรทัดด้วย `\n` / `\r\n` เท่านั้น ต้องเป็น UTF-8 · BOM ข้ามให้) |
| ไฟล์ (หลายไฟล์ได้) | — | แปลงไฟล์ (ข้อ 5) |
| `--teach คำ คำ-อ่าน` | — | บันทึกคำอ่านของคุณ (คำต้องเป็นอักษรไทยล้วน) |
| `--menu` | — | เมนูโต้ตอบ |
| `--json` | `--text` `--stdin` | ผลเป็น JSON (`--stdin --json` ได้ list เสมอ) |
| `--out โฟลเดอร์` | ไฟล์ | เก็บไฟล์ผลในโฟลเดอร์นี้ (สร้างให้) ชื่อซ้ำจะเติม `(2)` |
| `--keys a,b` | ไฟล์ .json .jsonl .tsv | แปลงเฉพาะ key / หัวคอลัมน์ (หรือเลขคอลัมน์) เหล่านี้ |
| `--mode irregular\|changed\|all` | ทุกแบบ | ข้อ 6 (ค่าเริ่มต้น `irregular`) |
| `--style c\|dict` | ทุกแบบ | รูปแบบคำอ่าน ข้อ 6 (ค่าเริ่มต้น `c` หรือตามตัวแปร `THAI_READ_STYLE`) · `dict` = ไม่มีขีด |
| `--pali` | ทุกแบบ | อ่านบาลีอักษรไทยด้วยกฎ |
| `--no-numbers` | ทุกแบบ | ไม่แปลงตัวเลข เวลา วันที่ อักษรย่อ |

ใช้ได้ทีละอย่างต่อครั้ง: `--text` / `--stdin` / `--teach` / `--menu` / ไฟล์

### ผล JSON

```json
{"input": "ค่าธรรมเนียม 200 บาท",
 "reading": "ค่า-ทำ-เนียม สองร้อย บาท",
 "changes": [{"word": "ธรรมเนียม", "reading": "ทำ-เนียม", "source": "wiktionary", "why": "..."}]}
```

`source` = `my` (ของคุณ) · `wiktionary` · `wiktionary-bound` (รูปเชื่อมคำสมาส) · `pali-rule`
· `reading` ใน `changes` เขียนตาม `--style` (แบบ `dict` ไม่มีขีด)

### Exit code

| code | ความหมาย |
|---|---|
| 0 | สำเร็จ |
| 1 | บางไฟล์ / stdin / --teach ล้มเหลว (ไฟล์อื่นยังทำต่อ) |
| 2 | อาร์กิวเมนต์ผิด หรือไม่มีอะไรให้ทำ (เช่น ไม่ใส่อาร์กิวเมนต์และไม่ได้รันในหน้าต่าง) |
| 3 | ไฟล์ข้อมูลใน `data/` หาย (โฟลเดอร์ไม่ครบ) |

## 5. แปลงไฟล์

| ไฟล์ | ส่วนที่แปลง | ส่วนที่ไม่แตะ |
|---|---|---|
| `.txt` | ทุกบรรทัดที่มีภาษาไทย | บรรทัดไม่มีภาษาไทย, บรรทัดขึ้นต้นด้วย `#` |
| `.srt` `.vtt` | ข้อความซับ | เลขลำดับ, เวลา, แท็ก `<i>` `<font>` `{\an8}` |
| `.ass` `.ssa` | ช่อง Text ของบรรทัด Dialogue | สไตล์, เวลา, ส่วนหัว |
| `.tsv` | ทุกคอลัมน์ที่มีไทย (หรือตาม `--keys`) | แถวหัวตาราง, คอลัมน์ที่เป็น path/URL |
| `.json` `.jsonl` | ค่าที่เป็นข้อความไทย (หรือตาม `--keys`) | key, ตัวเลข, path, URL, การย่อหน้า |
| อื่น ๆ | ถือเป็นข้อความทีละบรรทัด | — |

- ย่อหน้า ช่องว่าง NBSP tab BOM และ CRLF คงเดิม → เปิดไฟล์ใหม่ในโปรแกรมเดิมได้เลย
- ไฟล์ผลชื่อ `<ชื่อ>_อ่าน<นามสกุล>` (ไฟล์ `*_อ่าน.*` ถูก gitignore ไว้)
- **ไฟล์ต้องเป็น UTF-8** ไม่งั้นขึ้น `[error] ... not UTF-8` และข้ามไฟล์นั้น
- stdout: `[ok] ต้นทาง -> ปลายทาง (N lines changed)` · ไฟล์ที่พัง: `[error] ไฟล์: เหตุผล` ทาง stderr

แปลงเฉพาะข้อความพากย์ ไม่แตะซับ:

```bat
python thai_read.py lines.json --keys voice
python thai_read.py script.tsv --keys th_voice
```

## 6. โหมดการแปลง

| โหมด | แปลงคำไหน | ใช้เมื่อ |
|---|---|---|
| `irregular` (ค่าเริ่มต้น) | เฉพาะคำที่ตัวสะกดหลอก: การันต์, พยางค์เชื่อมที่ไม่ได้เขียน (ราชการ เอกสาร), ห นำหลังสระ ะ (ตระหง่าน), คำไม่ทั่วไปที่อ่านต่างจากตัวเขียน (อุโบสถ ประดิษฐาน) | งานทั่วไป ปลอดภัยที่สุด |
| `changed` | ทุกคำที่คำอ่านในพจนานุกรมต่างจากตัวสะกด รวมคำทั่วไป | โมเดลเสียงอ่านคำทั่วไปผิดด้วย |
| `all` | ทุกคำที่มีในพจนานุกรม เขียนแบบ C | อยากเห็นคำอ่านทุกคำ |

ข้อควรรู้เรื่อง `changed` / `all`: คำอ่านจาก Wiktionary เขียนแบบสัทอักษร คำทั่วไปบางคำจะได้ตัวสะกดแปลก
(เข้า → เค่า, ได้ → ด้าย, ก็ → เก้าะ) เสียงเท่ากันแต่โมเดลเสียงอาจอ่านเพี้ยน ฟังเทียบก่อนใช้จริง
ถ้าต้องการ "ทุกคำ ทุกพยางค์" แบบไม่เพี้ยน ดูตัวแปลงของสายงานเที่ยวในข้อ 13

### รูปแบบคำอ่าน: แบบ C หรือ แบบพจนานุกรม (`--style`)

`--mode` เลือกว่าแปลง**คำไหน** ส่วน `--style` เลือกว่าเขียนคำอ่านออกมา**หน้าตาแบบไหน** (ใช้คู่กันได้ทุกโหมด)

| ข้อความเดิม | `--style c` (ค่าเริ่มต้น) | `--style dict` (แบบพจนานุกรม) |
|---|---|---|
| ค่าธรรมเนียม 200 บาท | ค่า-ทำ-เนียม สองร้อย บาท | ค่าทำเนียม สองร้อย บาท |
| พระอุโบสถ | พระ-อุ-โบ-สด | พระอุโบสด |
| พระพุทธศาสนา | พระ-พุด-ทะ-สาด-สะ-หนา | พระพุดทะสาดสะหนา |
| ราชการ / ประดิษฐาน | ราด-ชะ-กาน / ประ-ดิด-สะ-ถาน | ราดชะกาน / ประดิดสะถาน |
| ลด 50% · ร.ศ. 112 | ลด ห้าสิบ เปอ-เซ็น · รัด-ตะ-นะ-โก-สิน-สก ... | ลด ห้าสิบ เปอเซ็น · รัดตะนะโกสินสก ... |
| พ.ศ. 2560 | พุทธศักราช สองพันห้าร้อยหกสิบ *(คงตัวเขียน)* | พุดทะสักกะหราด สองพันห้าร้อยหกสิบ |
| พระปรางค์สูงตระหง่าน | พระ-ปราง-สูง-ตระ-หง่าน | พระปรางสูงตระหง่าน |

- `dict` = คำอ่านจากพจนานุกรมเดียวกับแบบ C ทุกตัวอักษร ต่างกันแค่ไม่มีขีด (ทดสอบแล้วกับคำในพจนานุกรมทั้ง 33,000 คำ × 3 โหมด)
  ยกเว้นชื่อศักราช ซึ่งแบบ C คงตัวเขียนไว้ แต่แบบ `dict` ใช้คำอ่าน (พุทธศักราช → พุดทะสักกะหราด, ข้อ 7)
- คำที่แบบ C เปลี่ยนแค่ "ใส่ขีด" (ตระหง่าน → ตระ-หง่าน) แบบ `dict` ได้ตัวเขียนเดิม จึงไม่ถูกนับเป็นคำที่เปลี่ยน
- ขีดที่มีอยู่ในข้อความเดิม (`COVID-19`, `ไป-กลับ`) และแท็กซับ ไม่ถูกแตะ
- คำอ่านใน `data/` และ `my_readings.txt` ยังเก็บแบบมีขีดเหมือนเดิม — โปรแกรมลบขีดให้ตอนแปลง จึงสลับแบบได้ทุกเมื่อ
- ทำไมต้องไม่มีขีด: เจ้าของฟังแล้ว (2026-10-23) แบบมีขีด MiniMax ลากเสียงยืดไปหน่อย
  (ส่วนผลฟังรอบ 2026-10-02 ในข้อ 1 เทียบแบบขีดกับแบบ "เว้นวรรค" ไม่ได้เทียบกับแบบเขียนติดกัน)
  แบบ C ยังเป็นค่าเริ่มต้นเพื่อไม่ให้ผลของคนที่ใช้อยู่เปลี่ยนเอง
- ตั้งเป็นค่าเริ่มต้นได้ด้วยตัวแปร `THAI_READ_STYLE=dict` (มีผลกับบรรทัดคำสั่ง เมนู และการลากไฟล์ ไม่มีผลกับ `Reader()` ใน Python)

**ลำดับความสำคัญของแหล่งคำอ่าน**

1. `data/my_readings.txt` — ของคุณ (ชนะทุกแหล่ง รวมถึงเมื่ออยู่ในคำที่ยาวกว่า)
2. `data/keep_as_written.txt` — คงตามตัวเขียน
3. `data/thai_readings.txt` — พจนานุกรม
4. กฎบาลี (เมื่อใส่ `--pali`)

## 7. ตัวเลข วันที่ เวลา อักษรย่อ

ปิดทั้งหมดได้ด้วย `--no-numbers`

| ประเภท | ตัวอย่าง → คำอ่าน |
|---|---|
| ตัวเลข / หลักพัน | `2560` → สองพันห้าร้อยหกสิบ · `1,200` → หนึ่งพันสองร้อย |
| ทศนิยม | `35.50` → สามสิบห้า จุด ห้า ศูนย์ (จุดเป็นเวลาเฉพาะเมื่อมี น.) |
| เวลา | `08:30` / `18.30 น.` → แปด นาฬิกา สามสิบ นาที |
| ช่วง | `10:00-16:00` / `2556-2560` / `10-20%` → ... ถึง ... |
| ระยะเวลา | `2:15:30`, `1:30 ชม.`, `ใช้เวลา 1:30` → ชั่วโมง/นาที · `3:45 นาที`, `ยาว 3:45` → นาที/วินาที |
| วันที่ | `15 ม.ค. 2567`, `12.10.2560`, `12/10/2560`, `12-10-2567`, `2024-10-02` → วัน เดือน ปี |
| เปอร์เซ็นต์ / ติดลบ | `50%` → ห้าสิบ เปอ-เซ็น · `-5` → ลบ ห้า |
| เงิน | `฿1,200` → หนึ่งพันสองร้อย บาท · `350.-` → สามร้อยห้าสิบ |
| ทับ / ต่อ | `99/1` → ทับ · `บาท/คน`, `กม./ชม.` → ต่อ (เฉพาะระหว่างหน่วย; ชาย/หญิง ไป/กลับ คงเดิม) · `1:50,000` → ต่อ |
| คะแนน | หลัง ชนะ / แพ้ → ต่อ |
| เบอร์โทร | `02-123-4567`, `053-248604`, `08-1234-5678`, `0 2250 5500`, `(02) 123-4567`, `+66 ...` → อ่านทีละตัว |
| เลขขึ้นต้นด้วย 0 / สายด่วน / รหัสไปรษณีย์ | อ่านทีละตัว (รหัสไปรษณีย์ 5 หลักหลัง "ไปรษณีย์" หรือท้ายที่อยู่) |
| เลขไทย | `๒๕๖๐` แปลงเหมือนเลขอารบิก |

**ศักราช** (อ่านชื่อเต็ม ไม่ใช่ "พอ-สอ"):
`พ.ศ.` → พุทธศักราช · `ค.ศ.` → คริสต์ศักราช · `จ.ศ.` → จุลศักราช · `ร.ศ.` → รัด-ตะ-นะ-โก-สิน-สก
(รับรูป `พ. ศ.`, `...พ.ศ.`, `1.พ.ศ.` ด้วย · `ก.ค.ศ.` ไม่ใช่ศักราช ไม่แตะ)

| ชื่อศักราช | `--style c` (ค่าเริ่มต้น) | `--style dict` |
|---|---|---|
| พ.ศ. | พุทธศักราช *(คงตัวเขียน)* | พุดทะสักกะหราด |
| ค.ศ. | คริสต์ศักราช *(คงตัวเขียน)* | คริดสักกะหราด |
| จ.ศ. | จุลศักราช *(คงตัวเขียน)* | จุนละสักกะหราด |
| ร.ศ. | รัด-ตะ-นะ-โก-สิน-สก | รัดตะนะโกสินสก |

แบบ C คงชื่อศักราชตามตัวเขียน เพราะ MiniMax H3 ออกเสียงท้าย "หราด" ถูกเฉพาะจากตัวสะกดเดิม
(ทดสอบฟังคำอ่านแบบมีขีด 6 แบบ × 3 เทค 2026-10-02: หราด หร่าด หฺราด หลาด ออกเป็น "ราด" หมด)
แบบ `dict` เขียนคำอ่านติดกันตามที่เจ้าของสั่ง (2026-10-23) — ยังไม่ได้ฟังว่าท้าย "หราด" ออกถูกหรือไม่
ถ้าฟังแล้วเป็น "ราด" ให้เอา `[c]` หลังชื่อศักราชใน `data/keep_as_written.txt` ออก (จะคงตัวเขียนทั้งสองแบบ)
· ถ้าอยากได้คำอ่านในแบบ C ด้วย ให้ลบบรรทัดชื่อศักราชออก

## 8. สอนคำอ่านเอง / คงตามตัวเขียน

```
ธรรมเนียม = ทำ-เนียม
```

**วิธีเขียนคำอ่าน:** พยางค์ต่อกันด้วยขีด `-` (ตระ-หง่าน, ประ-ดิด-สะ-ถาน) อย่าเว้นวรรคระหว่างพยางค์

### `data/keep_as_written.txt` — คงตามตัวเขียน

คำที่โมเดลเสียงรู้จักอยู่แล้ว การสะกดตามเสียงกลับทำให้แย่ลง หนึ่งคำต่อบรรทัด ข้อความหลัง `#` คือหมายเหตุ
ใส่ป้าย `[c]` หลังคำ = คงตัวเขียนเฉพาะแบบ C (แบบ `dict` ได้คำอ่าน) · `[dict]` = เฉพาะแบบ `dict` · ไม่ใส่ = ทุกแบบ ค่าเริ่มต้น:

| คำ | ป้าย | เหตุผล (ฟังจริงกับ MiniMax H3) |
|---|---|---|
| ทรง | — | สะกด "ซง" แล้วได้ยินเป็น "สอง" |
| พุทธศักราช คริสต์ศักราช คริสตศักราช จุลศักราช มหาศักราช | `[c]` | สะกดแบบมีขีดทุกแบบออกท้ายเป็น "ราด" · แบบ `dict` เจ้าของขอคำอ่าน พุดทะสักกะหราด |

คำในรายการนี้ที่อยู่ในคำที่ยาวกว่าก็คงตามตัวเขียนด้วย (ทรงพระเจริญ → ทรง ไม่ใช่ ซง)

## 9. ให้ AI ตัวอื่นเรียกใช้

รายละเอียดเต็มอยู่ใน [AGENTS.md](AGENTS.md) สรุปกติกา:

- เรียก `python thai_read.py ...` **ตรง ๆ** (Windows ใช้ `py -3` ได้) — อย่าส่งข้อความผ่าน `.bat`
  เพราะ cmd.exe ส่งข้อความที่มี `"` ปนกับ `& | < > ^` ไม่ได้
- ตั้ง `PYTHONUTF8=1` (หรือ `PYTHONIOENCODING=utf-8`) ก่อนอ่าน stdout บน Windows
- Windows PowerShell 5.1: pipe เข้า Python เป็น ASCII (ไทยกลายเป็น `?`) → ใช้ไฟล์หรือ `--text` แทน
  หรือรัน `[Console]::OutputEncoding = $OutputEncoding = [Text.UTF8Encoding]::new()` ก่อน
- ใช้ผลกับ**เสียงเท่านั้น** ซับใช้ข้อความเดิม
- ใช้ `--json` เมื่อต้องรู้ว่าเปลี่ยนคำไหน · ตรวจ exit code (ข้อ 4)

**ข้อความสั่ง AI ตัวอื่น (คัดลอกไปวางได้)**

```
ก่อนส่งข้อความภาษาไทยให้โมเดลเสียงอ่าน ให้แปลงเป็นคำอ่านด้วย thai-reading
(ในเครื่องนี้: D:\AntigravityRepo\tools\thai-reading · หรือ https://github.com/chatcpeg/thai-reading)
อ่าน AGENTS.md ก่อนใช้
- เรียก python thai_read.py โดยตรง ตั้ง PYTHONUTF8=1 (อย่าส่งข้อความผ่าน .bat)
- ข้อความเดียว:  python thai_read.py --text "<ข้อความ>" --json
- ทั้งไฟล์:      python thai_read.py <ไฟล์> --out <โฟลเดอร์>
- ใช้ผลลัพธ์กับ "เสียง" เท่านั้น ซับไตเติลใช้ข้อความเดิมที่สะกดถูก

- คำที่สะกดตามเสียงแล้วแย่กว่าเดิม: ใส่ใน data/keep_as_written.txt
```

## 10. ใช้จาก Python

```python
import sys
sys.path.insert(0, r"D:\AntigravityRepo\tools\thai-reading")
import thai_read

R = thai_read.Reader()                                   # Reader(use_pali=True) เพิ่มกฎบาลี
reading, changes = R.read("ค่าธรรมเนียม 200 บาท")          # ("ค่า-ทำ-เนียม สองร้อย บาท", [...])
reading, _ = R.read("ข้อความ", mode="changed", numbers=False)

RD = thai_read.Reader(style="dict")                      # แบบพจนานุกรม ไม่มีขีด
RD.read("ค่าธรรมเนียม 200 บาท")[0]                         # "ค่าทำเนียม สองร้อย บาท"
R.style = "dict"                                         # หรือสลับ Reader เดิม ("c" = กลับเป็นแบบ C)
dst, n = R.convert_file("script.txt")                    # ("script_อ่าน.txt", จำนวนบรรทัดที่เปลี่ยน)
dst, n = R.convert_file("lines.json", out_dir="ผลลัพธ์", keys=["voice"])
R.teach("ธรรมเนียม", "ทำ-เนียม")                           # บันทึกลง my_readings.txt

# ใช้ไฟล์ข้อมูล / my readings ชุดอื่น
R2 = thai_read.Reader(data_dir=r"...\data", my_file=r"...\my.txt")

# เครื่องมือย่อย
```

## English

`thai-reading` turns Thai text into its **spoken reading** for TTS / AI voice models that read Thai letter by
letter. Syllables are joined by `-` ("style C"); `--style dict` writes the same dictionary reading solid, without
`-` (ค่าทำเนียม). Subtitles keep the real spelling; only the voice text changes.
By default only misleading spellings are respelled (silent letters, hidden linking syllables, rare words read
differently); digits, times, dates, ranges, %, phone numbers, era names and common abbreviations become words.
Files (.txt .srt .vtt .ass .tsv .json .jsonl) keep their layout. Python 3.8+, standard library only.
Machine interface: `AGENTS.md`. Code MIT; data CC BY-SA 4.0 (Wiktionary via wiktextract/kaikki.org) + CC0
(PyThaiNLP TNC frequencies).
