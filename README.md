# thai-reading — คำอ่านภาษาไทยสำหรับเสียงพากย์ AI (แบบ C: พยางค์คั่นขีด)

โมเดลเสียง AI หลายตัว (เช่น MiniMax H3) อ่านภาษาไทย **ตามตัวสะกด** จึงอ่านผิดกับคำที่มีตัวการันต์, ร ไม่ออกเสียง,
สระไม่ออกเสียงท้ายคำ (ชาติ), พยางค์เชื่อมที่มองไม่เห็น (ราชการ = ราด-ชะ-กาน), คำบาลี-สันสกฤต, อักษรย่อ และตัวเลข
เครื่องมือนี้แปลงข้อความเป็น **คำอ่าน** ให้โมเดลเสียงอ่าน — ซับไตเติลยังใช้ตัวสะกดจริงตามเดิม

| เขียน | อ่าน (แบบ C) |
|---|---|
| พระปรางค์สูงตระหง่าน | พระ-ปราง-สูง-ตระ-หง่าน |
| พระอุโบสถ | พระ-อุ-โบ-สด |
| ค่าธรรมเนียม | ค่า-ทำ-เนียม |
| พระพุทธศาสนา | พระ-พุด-ทะ-สาด-สะ-หนา |
| ทศวรรษ 1970 | ทด-สะ-วัด หนึ่งพันเก้าร้อยเจ็ดสิบ |
| ราคา 35.50 บาท | ราคา สามสิบห้า จุด ห้า ศูนย์ บาท |
| เปิด 10.00-16.00 น. | เปิด สิบ นาฬิกา ถึง สิบหก นาฬิกา |
| 15 ม.ค. 2567 · 5 กม. · โทร 02-123-4567 | สิบห้า มกราคม สองพันห้าร้อยหกสิบเจ็ด · ห้า กิโลเมตร · โทร ศูนย์ สอง, หนึ่ง สอง สาม, ... |
| ผู้ใหญ่ ภายใน ข้าวเหนียว | ผู้ใหญ่ ภายใน ข้าวเหนียว *(คำทั่วไป อ่านตามตัวเขียนได้อยู่แล้ว — ไม่แตะ)* |

**แบบ C** = แต่ละพยางค์ต่อกันด้วยขีด `-` (ทดสอบกับ MiniMax H3: "ตระ-หง่าน" ออกเสียงวรรณยุกต์ถูกทุกเทค
และไม่กระตุก ส่วนแบบเว้นวรรค "ตระ หง่าน" ถูกครึ่งเดียว)

## ใช้งาน

ต้องมี Python 3.8+ เท่านั้น (ไม่ต้องติดตั้งไลบรารีเพิ่ม)

```bat
ThaiReading.bat                                   :: เมนู: พิมพ์คำ / ใส่ไฟล์ / สอนคำอ่าน
ThaiReading.bat --text "พระปรางค์สูงตระหง่าน"     :: พิมพ์คำอ่าน
ThaiReading.bat script.txt subs.srt                :: หรือลากไฟล์มาวางบน .bat -> script_อ่าน.txt, subs_อ่าน.srt
ThaiReading.bat --teach ธรรมเนียม ทำ-เนียม          :: บันทึกคำอ่านของตัวเอง (ชนะทุกแหล่ง)
```

macOS / Linux / Git Bash: `./thai-read.sh` (อาร์กิวเมนต์เดียวกัน) · AI / สคริปต์: เรียก `python thai_read.py ...` ตรง ๆ (ดู `AGENTS.md`)

**ไฟล์** (.txt .srt .vtt .tsv .json .jsonl .ass): แปลงเฉพาะข้อความไทย รูปแบบเดิมทุกอย่าง — บรรทัดไม่มีภาษาไทย (เลขลำดับ/เวลาใน .srt, บรรทัด `#`) ไม่แตะ,
ทุกคอลัมน์ที่คั่นด้วย tab คงอยู่, ย่อหน้า/ช่องว่าง/NBSP/BOM/CRLF คงเดิม, แท็กซับ (`<font>`, `{\an8}`) ไม่แตะ,
`.json` / `.jsonl` คง key และการย่อหน้า — แปลงเฉพาะค่าที่เป็นข้อความไทย ไม่แตะค่าที่เป็น path/URL
(เลือกเองได้ด้วย `--keys th,voice` ทั้ง JSON และหัวคอลัมน์ `.tsv` — เช่นแปลงคอลัมน์เสียง ไม่แตะคอลัมน์ซับ)

**โหมด** (`--mode`)
- `irregular` (ค่าเริ่มต้น) — แปลงเฉพาะคำที่ตัวสะกดหลอก: ตัวการันต์, พยางค์เชื่อมที่ไม่ได้เขียน
  (ราชการ เอกสาร), ห นำหลังสระ ะ (ตระหง่าน) และคำที่ไม่ใช่คำทั่วไปซึ่งอ่านต่างจากตัวเขียน (อุโบสถ ประดิษฐาน)
  · **ไม่มั่นใจ = คงตามตัวเขียน**: คำทั่วไปและวลีที่ประกอบจากคำทั่วไป (ผู้ ใน ร้านอาหาร อย่างไรก็ตาม เกียรติ) ไม่แตะ
- `changed` — แปลงทุกคำที่คำอ่านต่างจากตัวสะกด
- `all` — ทุกคำที่มีในพจนานุกรมเขียนแบบ C
- `--pali` — อ่านบาลีอักษรไทย (ธมฺม → ธัม-มะ) ด้วยกฎ · `--no-numbers` — ไม่แปลงตัวเลข/อักษรย่อ

**ลำดับความสำคัญ:** `data/my_readings.txt` (ของคุณ) > `data/keep_as_written.txt` (คงตามตัวเขียน) >
`data/thai_readings.txt` (พจนานุกรม) > กฎบาลี (เมื่อใส่ `--pali`)

**คำสมาส:** ใช้รูปเชื่อม (มีพยางค์เชื่อม) เฉพาะหลัง พุทธ ราช บรม ธรรม ที่ตามด้วยคำนามบาลี-สันสกฤต
(พุทธ+ศาสนา = พุด-ทะ-สาด-สะ-หนา) · คำเรียงแบบไทย (ยามพระอาทิตย์ตก ฐานพระประธาน อากาศสบาย ประเทศไทย),
คำที่อาจเป็นต้นคำสมาสแต่ไม่แน่ใจ และคำที่หาไม่เจอว่าแยกยังไง (ราชวรมหาวิหาร) คงตามตัวเขียน — ไม่เดาให้ผิด

## ข้อมูล

| ไฟล์ | เนื้อหา |
|---|---|
| `data/thai_readings.txt` | คำไทย ~33,000 คำ `คำ<TAB>คำอ่าน` จาก Wiktionary (อังกฤษ + ไทย) รวมคำยืมบาลี-สันสกฤต ผ่านการตรวจความสมเหตุสมผลแล้ว |
| `data/thai_bound_forms.txt` | รูปเชื่อมในคำสมาส (พุทธ → พุด-ทะ) |
| `data/thai_origins.txt` | ที่มาของคำยืม (pali / sanskrit / khmer / chinese / english ...) |
| `data/thai_readings_full.tsv` | รวมทุกคอลัมน์ |
| `data/suspect_readings.tsv` | คำอ่านใน Wiktionary ที่ไม่ผ่านการตรวจ (ไม่ถูกใช้) |
| `data/common_words.txt` | 2,500 คำที่ใช้บ่อยที่สุด (คลังข้อมูลภาษาไทยแห่งชาติ ผ่าน PyThaiNLP, CC0) |
| `data/pali_thai_script.txt` | คำบาลีอักษรไทย ~7,700 รูป — **คำอ่านสร้างด้วยกฎ ไม่ใช่จากพจนานุกรม** |
| `data/abbreviations.txt` | อักษรย่อ → คำเต็ม (เดือน หน่วย จังหวัด คำนำหน้า รศ. ดร. นพ. ฯ) แก้ไขได้ · พ.ศ. ค.ศ. จ.ศ. ร.ศ. อ่านชื่อศักราชเต็ม (พ.ศ. = พุด-ทะ-สัก-กะ-หราด) |
| `data/keep_as_written.txt` | คำที่ให้คงตามตัวเขียน (เช่น ทรง — โมเดลเสียงอ่านคำอ่าน "ซง" แย่กว่า) |
| `data/my_readings.txt` | คำอ่านของคุณเอง |

สร้างใหม่จากต้นทางล่าสุด: `pip install pythainlp` แล้ว `python tools/build_data.py`
(ดาวน์โหลด dump ของ kaikki.org ~160 MB ลง `_raw/`)

พจนานุกรมฉบับราชบัณฑิตยสภาไม่ได้รวมไว้ในชุดข้อมูลนี้ เพราะเป็นงานมีลิขสิทธิ์ เผยแพร่ซ้ำไม่ได้

## English

`thai-reading` turns Thai text into its **spoken reading** for TTS / AI voice models that read Thai letter by
letter. Syllables are joined by `-` ("style C"). Subtitles keep the real spelling; only the voice text changes.
By default only misleading spellings are respelled (silent letters, hidden linking syllables, rare words read
differently); digits, times, dates, ranges, %, phone numbers and common abbreviations become words.
Python 3.8+, standard library only. Machine interface: `AGENTS.md`. Code MIT; data CC BY-SA 4.0
(Wiktionary via wiktextract/kaikki.org) + CC0 (PyThaiNLP TNC frequencies).
